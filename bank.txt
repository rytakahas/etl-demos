I’ll assume this definition of profit (you can say it out loud in the interview):

Gross income ≈ sum of interest_component + fee_component from f_payment

Credit loss ≈ sum of (default_amount - recovery_amount) from f_default_event

Net profit = gross income − credit loss

Period: 2025-01-01 → 2025-05-31
Grain: per dealer (with number of distinct customers).

SQL with CTEs (dealer → customers & profit Jan–May 2025)
-- 1) Aggregate payments (income) per dealer in Jan–May 2025
WITH payments_agg AS (
    SELECT
        p.dealer_key,
        p.country_entity_key,
        COUNT(DISTINCT p.customer_key) AS num_customers,
        SUM(p.interest_component + p.fee_component) AS gross_income
    FROM f_payment p
    JOIN dim_date d
        ON d.date_key = p.payment_date_key
    WHERE d.full_date BETWEEN DATE '2025-01-01' AND DATE '2025-05-31'
    GROUP BY
        p.dealer_key,
        p.country_entity_key
),

-- 2) Aggregate credit losses (defaults - recoveries) per dealer in same period
defaults_agg AS (
    SELECT
        de.dealer_key,
        de.country_entity_key,
        SUM(de.default_amount - de.recovery_amount) AS credit_loss
    FROM f_default_event de
    JOIN dim_date d
        ON d.date_key = de.default_date_key
    WHERE d.full_date BETWEEN DATE '2025-01-01' AND DATE '2025-05-31'
    GROUP BY
        de.dealer_key,
        de.country_entity_key
),

-- 3) Combine income and losses to compute net profit per dealer
profit_by_dealer AS (
    SELECT
        p.dealer_key,
        p.country_entity_key,
        p.num_customers,
        p.gross_income,
        COALESCE(d.credit_loss, 0) AS credit_loss,
        p.gross_income - COALESCE(d.credit_loss, 0) AS net_profit
    FROM payments_agg p
    LEFT JOIN defaults_agg d
        ON p.dealer_key = d.dealer_key
       AND p.country_entity_key = d.country_entity_key
)

-- 4) Final output: dealer name, location, country, ordered by profit desc
SELECT
    dd.dealer_name,
    dd.city,
    ce.country_code,
    ce.country_name,
    profit.num_customers,
    profit.gross_income,
    profit.credit_loss,
    profit.net_profit
FROM profit_by_dealer profit
JOIN dim_dealer dd
    ON profit.dealer_key = dd.dealer_key
JOIN dim_country_entity ce
    ON profit.country_entity_key = ce.country_entity_key
ORDER BY
    profit.net_profit DESC;

How you can explain this in the interview

You (summarizing):

“I’d define a CTE payments_agg that aggregates all payments between January and May 2025, counting distinct customers and summing interest and fees as gross income per dealer and country/entity.

       AND m.country_entity_key = d.country_entity_key
       AND m.fuel_type = d.fuel_type
),

-- 4) Add dealer & country info + window functions
ranked AS (
    SELECT
        ce.country_code,
        ce.country_name,
        p.fuel_type,
        dd.dealer_name,
        dd.city,
        p.num_customers,
        p.total_volume,
        p.gross_margin_eur,
        p.credit_loss_eur,
        p.net_profit_eur,

        -- Rank dealers inside each (country, fuel_type) by net profit
        RANK() OVER (
            PARTITION BY ce.country_code, p.fuel_type
            ORDER BY p.net_profit_eur DESC
        ) AS rank_in_country_fuel,

        -- Share of total net profit for that (country, fuel_type) segment
        p.net_profit_eur
        / NULLIF(
            SUM(p.net_profit_eur) OVER (
                PARTITION BY ce.country_code, p.fuel_type
            ),
            0
        ) AS profit_share_in_segment
    FROM profit_by_dealer p
    JOIN dim_dealer dd
        ON p.dealer_key = dd.dealer_key
    JOIN dim_country_entity ce
        ON p.country_entity_key = ce.country_entity_key
)

SELECT
    country_code,
    country_name,
    fuel_type,
    dealer_name,
    city,
    num_customers,
    total_volume,
    net_profit_eur,
    rank_in_country_fuel,
    profit_share_in_segment
FROM ranked
WHERE fuel_type IN ('EV', 'ICE', 'Hybrid')  -- optional filter
ORDER BY
    country_code,
    fuel_type,
    rank_in_country_fuel;

How to explain the window functions

You:

“In the final CTE ranked I use two window functions:

RANK() OVER (PARTITION BY country_code, fuel_type ORDER BY net_profit_eur DESC)
→ gives each dealer a rank inside that country and fuel type (e.g. top 3 EV dealers in Germany).

SUM(net_profit_eur) OVER (PARTITION BY country_code, fuel_type)
→ gives total net profit for that segment; then I divide each dealer’s profit by that total to get profit_share_in_segment.

This way I can compare, per country, which dealers are strongest for EV, Hybrid, or ICE — both in absolute profit and as a share of that segment.”

2) Monthly EV vs ICE vs Hybrid trend using window functions

Now you want to see trends over time (Jan–May 2025) for EV / Hybrid / ICE per country.

We can measure:

Monthly volume (approved_amount) per (country, month, fuel_type)

EV / Hybrid / ICE share inside each (country, month)

Window function gives us the denominator (total volume in that country-month).

-- 1) Monthly contract volume per country & fuel_type
WITH contracts_month AS (
    SELECT
        ce.country_code,
        v.fuel_type,
        DATE_TRUNC('month', d.full_date) AS month_start,
        SUM(c.approved_amount) AS total_volume_eur
    FROM f_contract_retail c
    JOIN dim_date d
        ON d.date_key = c.orig_date_key
    JOIN dim_country_entity ce
        ON ce.country_entity_key = c.country_entity_key
    JOIN dim_vehicle v
        ON v.vehicle_key = c.vehicle_key
    WHERE d.full_date BETWEEN DATE '2025-01-01' AND DATE '2025-05-31'
    GROUP BY
        ce.country_code,
        v.fuel_type,
        DATE_TRUNC('month', d.full_date)
),

-- 2) Compute EV/ICE/Hybrid share within each country+month
with_share AS (
    SELECT
        country_code,
        fuel_type,
        month_start,
        total_volume_eur,

        -- Window: total volume that month in that country (all fuel types)
        total_volume_eur
        / NULLIF(
            SUM(total_volume_eur) OVER (
                PARTITION BY country_code, month_start
            ),
            0
        ) AS volume_share_in_month
    FROM contracts_month
)

SELECT
    country_code,
    month_start,
    fuel_type,
    total_volume_eur,
    volume_share_in_month
FROM with_share
WHERE fuel_type IN ('EV', 'Hybrid', 'ICE')  -- optional
ORDER BY
    country_code,
    month_start,
    fuel_type;

How to explain this one

You:

“Here I’m not ranking dealers but looking at trends by fuel type.

In contracts_month I aggregate approved_amount per (country, month, fuel_type) for Jan–May 2025.

In with_share I use a window function:
SUM(total_volume_eur) OVER (PARTITION BY country_code, month_start)
to get the total financed volume in that country and month across all fuel types.

Then I divide each fuel_type volume by that total to get volume_share_in_month.

This shows, for each country and month, how much of the financed volume is EV, Hybrid, or ICE. You can plot volume_share_in_month over time to see if EV share is increasing and ICE shrinking.”
