# 10. WebProtégé workflow (optional)

Recommended workflow:
1) Ontology in Git is source-of-truth: `kg/ontology/hb_bank.ttl`
2) Auto-generate first-pass labels/comments/definitions from data dictionary
3) Upload to WebProtégé for review/comments
4) Export and commit back to Git

You do NOT have to edit everything by hand in WebProtégé, but final review is typically manual.
